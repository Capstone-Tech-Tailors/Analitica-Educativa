Resumen ejecutivo

Este informe documenta el diseño, la construcción, la evaluación y el despliegue de un sistema de análisis de sentimiento en español para los comentarios de las encuestas de evaluación docente, cuyo propósito final es alimentar la construcción del DOFA de cada docente de la Universidad del Rosario y un modelo complementario de tendencia de desempeño (Mejora / Estable / En riesgo).

El proyecto recorrió el ciclo completo de un desarrollo de ciencia de datos aplicada:

  1. Diagnóstico de datos. El análisis exploratorio reveló que el dataset institucional del reto contiene solo 20 comentarios distintos repetidos en 3.000 filas (unicidad 0,67 %), lo que imposibilita entrenar o evaluar seriamente un modelo de lenguaje. Este hallazgo redefinió la estrategia y motivó la incorporación de un corpus real complementario de 100.000 comentarios (29.243 textos únicos), traducido al español por el equipo.
  2. Evaluación comparativa de tres modelos de sentimiento aplicables al español —RoBERTuito y BETO (preentrenados en español) y XLM-R (multilingüe)— contra un estándar de oro manual: RoBERTuito resultó el mejor modelo individual (accuracy 0,75) y el consenso por votación el mejor macro-F1 (0,730).
  3. Modelo de tendencia docente: RandomForest con macro-F1 0,915 en partición aleatoria y 0,905 en validación temporal (entrenar 2020-2022, probar 2023), con detección y exclusión de una variable con fuga de información. El punto de operación desplegado —tras calibración isotónica y umbral 0,21— rinde macro-F1 0,899 con recall En riesgo 0,966.
  4. Fine-tuning por destilación: se demostró empírica y sistemáticamente que un modelo entrenado con pseudo-etiquetas de un maestro no puede superar al maestro (fidelidad de imitación de hasta 0,933, sin ganancia de calidad real), incluyendo un análisis de falsos positivos que probó que el error residual es un problema de definición de rúbrica y no de modelado.
  5. Anotación humana: el equipo diseñó y ejecutó un protocolo formal de etiquetado (335 comentarios, 3 anotadores independientes, 749 anotaciones) con acuerdo inter-anotador α de Krippendorff = 0,585 y un estándar de oro adjudicado de 172 comentarios, 8,6 veces mayor que el disponible previamente.
  6. Modelo final: el ajuste fino de RoBERTuito con las etiquetas humanas produce el mejor clasificador disponible sobre la evaluación humana (macro-F1 0,646; accuracy 0,762; recall de comentarios negativos 0,556), superando de manera consistente —aunque aún no estadísticamente significativa (McNemar p = 1,0)— al mejor modelo público (0,638).

El modelo final se empaquetó en un ZIP de 404 MB (modelo en disco: 437 MB, ejecutable en CPU) y se entregó para su despliegue en Azure; el informe incluye la guía completa de despliegue, la metodología de construcción del DOFA a partir de las salidas del modelo (con un prototipo sobre datos reales) y una declaración exhaustiva de limitaciones, entre ellas que el cuello de botella actual es el volumen de anotación humana, con el sistema para ampliarla ya construido y operativo.

1 · Introducción

1.1 Contexto del reto

El reto Analítica Educativa plantea evolucionar el análisis de las evaluaciones docentes desde un sistema descriptivo basado en reglas hacia una solución predictiva y accionable, capaz de anticipar tendencias en el desempeño docente y generar recomendaciones de mejora continua, manteniendo compatibilidad con los datos y procesos existentes.

1.2 Problema

Las encuestas de evaluación docente combinan puntajes numéricos (claridad, metodología, evaluación) con comentarios de texto libre. Los puntajes se procesan de forma rutinaria; los comentarios —que contienen la información más rica y accionable— quedan habitualmente sin explotar, porque requieren lectura humana masiva o tecnología de procesamiento de lenguaje natural. El problema abordado es doble:

  1. Clasificar automáticamente el sentimiento de cada comentario (positivo / neutro / negativo) con calidad suficiente para agregarlo por docente.
  2. Predecir la tendencia de desempeño combinando puntajes y sentimiento, para priorizar el acompañamiento pedagógico.

1.4 Alcance y no-alcance

Incluye: análisis exploratorio y auditoría del dataset institucional; benchmark de modelos; modelo de tendencia; dos rondas de fine-tuning (destilación y verdad humana); protocolo completo de anotación humana; empaquetado del modelo y guía de despliegue; metodología DOFA con prototipo.

No incluye: el despliegue productivo final en Azure (en ejecución por el equipo), la integración con el sistema de encuestas de la universidad, ni el análisis basado en aspectos (ABSA), que el corpus utilizado no permite (§3.2).

Los principios de diseño que gobernaron el proyecto:

  • Medir antes de elegir: ningún modelo se adoptó sin un benchmark contra referencia humana.
  • Honestidad estadística: toda comparación va acompañada de su prueba de significancia; los resultados no significativos se declaran como tales.
  • Trazabilidad total: semillas fijadas, sumas de comprobación, fichas info.json por modelo y ejecución reproducible de todos los notebooks.
  • El humano define la vara: la calidad se mide contra etiquetas humanas con acuerdo inter-anotador cuantificado, no contra las predicciones de otro modelo.

Tres señales indican que el campo no es texto libre real sino plantillado/anonimizado: (i) cero variaciones ortográficas y cero celdas vacías; (ii) cada frase repartida de forma casi uniforme entre docentes, semestres y asignaturas; (iii) independencia entre comentario y puntaje (p. ej. "Llega tarde a las clases frecuentemente" coexiste con puntajes de hasta 4,4).

Implicación. Para el análisis de texto, el conjunto real de evaluación son 20 elementos, no 3.000: el dataset sirve para validar el método, no para demostrar desempeño de NLP. Esto motivó la incorporación del segundo dataset.

4 · Metodología

El proyecto se ejecutó en seis fases encadenadas. Cada una respondió a una pregunta concreta y sus decisiones se justifican con evidencia obtenida en la fase anterior.

4.1 Fase 1 — Análisis exploratorio y auditoría

Se partió del análisis exploratorio del dataset institucional y se sometió a una auditoría sistemática: cada afirmación del EDA se recomputó desde los datos y la mayoría de los hallazgos se sometió además a refutadores independientes antes de aceptarse. Los cuatro hallazgos metodológicos de mayor severidad (§5.7) quedaron sin esa segunda vuelta por un límite de sesión; se recomputaron de forma independiente y así se declara.

La auditoría confirmó la calidad estructural (0 nulos, 0 duplicados, rangos válidos, paleta visual validada para daltonismo con ΔE CVD ≥ 23,8) y detectó seis problemas que se corrigieron antes de continuar: cuatro conclusiones sobre-afirmadas, la ubicación errónea de la «zona gris» y un artefacto en la señal de sentimiento (§5.7–§5.8).

4.2 Fase 2 — Benchmark de modelos preentrenados

Se compararon tres modelos de sentimiento en español contra un estándar de oro etiquetado manualmente por rúbrica, elaborado de forma independiente de los modelos para evitar circularidad al elegir entre ellos.

Modelo Identificador en Hugging Face
RoBERTuito pysentimiento/robertuito-sentiment-analysis
BETO finiteautomata/beto-sentiment-analysis
XLM-R (Twitter) cardiffnlp/twitter-xlm-roberta-base-sentiment

Rúbrica de etiquetado. POS = elogio o satisfacción clara; NEG = queja o crítica, incluida la crítica constructiva («se podría mejorar», «falta…»); NEU = descriptivo o administrativo, elogio tibio («estuvo bien», «cumple») o mixto sin polaridad dominante.

Se evaluó además una estrategia de consenso por votación mayoritaria de los tres modelos, con RoBERTuito como criterio de desempate.

4.3 Fase 3 — Modelo de tendencia docente

Clasificador de tendencia_desempeno a partir de puntajes y sentimiento. Se compararon cinco candidatos bajo dos protocolos de validación y con una restricción de negocio explícita: recall de la clase En riesgo ≥ 0,985 (el costo de no detectar a un docente que necesita acompañamiento supera al de una falsa alarma).

Selección de variables. Se excluyeron deliberadamente:

Variable excluida Motivo
delta_semestre Fuga de información: incorpora el promedio del semestre que se está clasificando; en grupos docente-semestre de tamaño 1 la variable es el puntaje propio
hist_prom_previo Sin poder predictivo demostrado
id_docente, semestre Alta cardinalidad sin señal real (V de Cramér de id_docente = 0,119 con p = 0,813; el valor esperado bajo independencia pura es 0,127, mayor que el observado)

4.4 Fase 4 — Fine-tuning por destilación (weak supervision)

Ante la ausencia de etiquetas en el corpus, se aplicó destilación de conocimiento (Hinton et al., 2015): RoBERTuito —el mejor modelo del benchmark— actuó como maestro etiquetando el corpus deduplicado, y BETO como alumno entrenado con esas pseudo-etiquetas.

Límite teórico declarado como hipótesis falsable. El alumno aprende la función del maestro, heredando sus aciertos y sus errores; su techo de calidad es, por construcción, el desempeño del maestro. La §5.3 contrasta esta hipótesis empíricamente, incluyendo una comparación de arquitecturas del alumno.

4.5 Fase 5 — Anotación humana

Única vía para romper el techo de la destilación. El equipo diseñó y ejecutó un protocolo formal de anotación (v1.0):

Muestreo estratificado de 335 comentarios. No es una muestra aleatoria simple: está deliberadamente enriquecida en casos fronterizos, que es donde se decide la rúbrica.

Estrato Ítems Contenido
H0_CENSO 40 Los 40 enunciados más frecuentes — concentran el 53 % de todas las evaluaciones
H1_CORTO 20 Textos de 1–2 palabras (pesan el 30 % de las filas)
H2a_T0 40 Casos triviales (control del estimador)
H2b_F1 80 Frontera débil: POS con alta confianza y léxico tibio
H3_F2 145 Frontera fuerte: máxima ambigüedad
H4_LARGO 10 Textos largos (control de longitud)
Total 335

Justificación del censo. Dos enunciados —«Es un buen profesor» (15.826 filas) y «Bueno.» (9.745 filas)— determinan por sí solos el 25,6 % del corpus. Un sorteo aleatorio tendría probabilidad casi nula de incluirlos, y sin ellos ninguna métrica podría traducirse a desempeño real. El sesgo de sobre-representación se corrige al estimar mediante ponderación estratificada (w_h = N_h / n_h).

Diseño de la anotación.

Bloque Diseño Realizado Anotación Destino
EVAL 185 184 anotados por los 3 → 178 tras exclusiones → 172 gold Los 3 anotadores (triple) Evaluación + medición de acuerdo

Los dos textos ilegibles de la muestra se retiraron antes de generar las planillas, por lo que 333 de los 335 ítems de diseño llegaron a anotarse.

Se incluyeron 8 ítems ancla de etiqueta obvia (control de atención) y 8 repetidos encubiertos (autoconsistencia). Decisiones de control: no se muestra la predicción del modelo —RoBERTuito acierta 15/16 en casos claros pero 0/4 en fronterizos, y la muestra está enriquecida precisamente en fronterizos, por lo que mostrar su predicción induciría anchoring bias justo donde importa—; orden aleatorizado independiente por anotador con claves opacas; formato XLSX (el 30 % de los textos contienen comas y el 51 % llevan tildes, lo que corrompe el viaje por CSV).

4.6 Fase 6 — Fine-tuning con verdad humana

Ajuste fino de robertuito-sentiment-analysis (continued fine-tuning) con las 148 etiquetas humanas. Al provenir la evaluación de personas y no del maestro, desaparece la circularidad que limitaba la fase anterior.

Por qué esta vez sí se ajusta RoBERTuito. En la Fase 4 el alumno debía ser un modelo distinto del maestro para evitar la auto-destilación. Al desaparecer esa restricción, conviene partir del modelo con mejor desempeño previo: con solo 148 ejemplos, un modelo que ya sabe clasificar sentimiento únicamente necesita ajustar la frontera POS/NEU, mientras que uno sin cabeza de clasificación no aprendería la tarea desde cero.

Hallazgo principal. Los errores se concentran en los 4 comentarios fronterizos —elogios tibios («La clase estuvo bien»), críticas constructivas («Se podría mejorar un poco el material de estudio») y mixtos con adversativa («Asistencia puntual, pero falta dinamismo»)—: ningún enfoque acierta más de 2 de los 4 y RoBERTuito falla los cuatro. Pero no se agotan ahí: cada enfoque comete además entre 1 y 5 errores en comentarios claros (RoBERTuito 1 · consenso 3 · XLM-R 4 · BETO 5). Dos fronterizos —«La clase estuvo bien» y «Se podría mejorar un poco el material de estudio»— fallan en los cuatro enfoques.

RoBERTuito es el más fuerte en comentarios claros (0,94). El consenso resuelve 2 de los 4 fronterizos, aunque a costa de 2 comentarios claros (0,81 frente a 0,94); con los mismos 15/20 aciertos, su macro-F1 es superior (0,730 vs 0,706) por un reparto más equilibrado del error entre clases, no por acertar más.

Conclusión. La dificultad no está en el modelo sino en la ambigüedad del lenguaje: dos personas razonables etiquetarían esos casos de forma distinta. Este hallazgo determina toda la estrategia posterior del proyecto.

# app.py
from fastapi import FastAPI
from pydantic import BaseModel
from transformers import pipeline

app = FastAPI(title="Sentimiento docente — U. del Rosario")
clf = pipeline("sentiment-analysis", model="/ruta/del/volumen/modelo_sentimiento_humano")

class Lote(BaseModel):
    comentarios: list[str]

@app.post("/sentimiento")
def sentimiento(lote: Lote):
    return [{"comentario": c, **r} for c, r in
            zip(lote.comentarios, clf(lote.comentarios, truncation=True, max_length=128))]

FROM python:3.12-slim

9 · Limitaciones

Se declaran de forma explícita porque condicionan la interpretación de todos los resultados.

9.1 Limitaciones de los datos

# Limitación Impacto Estado

9.3 Limitaciones del alcance

  • El DOFA prototipado usa agrupación por frecuencia de comentario, no modelado temático (no hay suficientes textos distintos para justificar topic modeling).
  • El pipeline está validado fuera de línea; no se ha ejecutado un ciclo completo en producción con datos de un semestre real.
  • El modelo de tendencia no alcanza el objetivo de recall ≥ 0,985 en el protocolo aleatorio (0,960 antes del ajuste de umbral, 0,966 después); sí lo alcanza en el protocolo temporal 2023 (0,993). Queda documentado como pendiente.

10 · Consideraciones éticas

Las salidas del modelo no son decisiones. Un sistema con macro-F1 de 0,646 y un recall NEG de 0,556 se equivoca de forma sistemática. Ninguna consecuencia laboral —renovación de contrato, evaluación de desempeño, sanción— debe derivarse automáticamente de sus predicciones. El uso legítimo es priorizar dónde mira una persona: señalar a qué docentes conviene acompañar y con qué evidencia textual.

Revisión humana obligatoria en el bucle. El DOFA generado es un borrador que un responsable académico lee, contrasta con el contexto (asignatura, tamaño de grupo, momento del plan de estudios) y edita antes de compartirlo con el docente.

Asimetría de errores. En este dominio, un falso negativo (no detectar una crítica real) es más costoso que un falso positivo: oculta un problema que la institución podría resolver. Por eso se priorizó el recall de la clase NEG en la selección del modelo, aun a costa de la precisión global.

Protección de datos. Los comentarios son opiniones sobre personas identificables. Se recomienda: seudonimizar los identificadores de docente antes de la inferencia, procesar en infraestructura controlada por la universidad, restringir el endpoint por token, y conservar solo los agregados necesarios para el DOFA —no los textos crudos vinculados a nombres.

Anonimato del estudiantado. Ningún artefacto del proyecto debe permitir reidentificar a quien escribió un comentario. En cursos pequeños, un comentario textual puede identificar a su autor; por eso los reportes deben publicarse agregados y con un mínimo de evaluaciones por docente.

Sesgo conocido y no medido. La literatura documenta sesgos de género y origen en las evaluaciones docentes escritas por estudiantes. Este proyecto no pudo medirlos (L11); un sistema que amplifique un sesgo presente en los datos lo convertiría en decisión institucional. Antes de un despliegue con consecuencias, es indispensable auditar el desempeño por subgrupo.

Transparencia. Los docentes evaluados deben saber que sus comentarios se procesan automáticamente, con qué finalidad, y tener derecho a revisar y objetar el DOFA resultante.

11 · Conclusiones

  1. El diagnóstico de los datos redefinió el proyecto. Descubrir que las 3.000 evaluaciones contienen solo 20 comentarios distintos (0,67 % de unicidad) fue el hallazgo más importante: invalidó el plan de entrenar directamente sobre el dataset institucional y obligó a construir una fuente de verdad propia. Sin ese diagnóstico, cualquier métrica reportada habría sido una ilusión estadística.

  2. La destilación tiene un techo estructural y quedó demostrado, no supuesto. El estudiante alcanzó una fidelidad de 0,9055 (BETO) y 0,9330 (RoBERTuito) frente al maestro, pero nunca lo igualó sobre el gold. Las tres hipótesis alternativas —más datos, menos regularización, otra arquitectura— se formularon de forma falsable y ninguna cerró la brecha. La conclusión es metodológica: no se puede superar a un maestro aprendiendo únicamente de sus etiquetas.

  3. Los falsos positivos por elogio tibio no son un problema de modelado. El barrido de umbrales lo probó cuantitativamente: el error es confiado (P = 0,993, mayor que la de varios aciertos reales) y el umbral más bajo que lo elimina (0,995) deja solo 2 de los 6 verdaderos positivos y hunde macro-F1 de 0,669 a 0,531. Es un problema de rúbrica, y solo la anotación humana podía resolverlo.

  4. La anotación humana rompió el techo. 749 anotaciones de 3 anotadores con α de Krippendorff de 0,585 (acuerdo moderado, con paradoja de kappa declarada y P_o = 0,787) produjeron un gold de 172 ítems, 8,6 veces mayor que el disponible antes. Ese conjunto reveló además que las métricas del benchmark original estaban infladas: RoBERTuito baja de 0,706 sobre 20 ítems a 0,638 sobre 172.

  5. El modelo final mejora al maestro de forma consistente, pero sin significancia estadística. modelo_sentimiento_humano obtiene macro-F1 0,646 · accuracy 0,762 · recall NEG 0,556, mejor que el maestro en las tres métricas, con McNemar p = 1,000. La afirmación honesta —y la que sostiene este informe— es que el ajuste con verdad humana funciona en la dirección correcta y necesita más datos anotados para demostrarlo con potencia.

  6. La brecha ordinal−nominal de +0,143 identificó exactamente dónde invertir. Los desacuerdos entre anotadores son adyacentes, no polares: el problema es de umbral de rúbrica, no de comprensión. Los 6 ítems sin mayoría son todos mixtos adversativos. Eso convierte «mejorar el modelo» en una tarea concreta: escribir reglas de decisión para los mixtos y volver a anotar.

  7. La auditoría del análisis exploratorio evitó cuatro errores publicables: una fuga de información (delta_semestre), un ranking de importancia invalidado por colinealidad, una variable sin señal real (id_docente, V de Cramér 0,119 con p = 0,813) y una ventaja del aprendizaje automático que no resiste una prueba de significancia (McNemar p = 0,280). La verificación adversarial no es burocracia: cambió conclusiones.

  8. El sentimiento aporta señal parcialmente independiente de los puntajes, y ahí está su valor para el DOFA. Cuatro docentes tienen puntaje por encima de la mediana y porcentaje de comentarios negativos en el cuartil superior —casos que el sistema de puntajes no detecta—. En la frontera de decisión real ([3,9 – 4,5]), incorporar el sentimiento aporta +0,04 de macro-F1.

  9. El artefacto está listo para producción y verificado: 437 MB, inferencia en CPU (2 vCPU · 4 GB), recargable desde disco de forma reproducible, y empaquetado en un ZIP de 404 MB probado extrayéndolo en un directorio limpio.

12 · Trabajo futuro

Ordenado por relación entre impacto y esfuerzo.

Prioridad 1 — Ampliar el gold anotado (impacto alto · esfuerzo medio). Duplicar el conjunto humano a 300–400 ítems, con énfasis en NEU (la clase con precisión 0,300) y en mixtos adversativos. Es la única intervención que ataca simultáneamente L3, L6 y L7. Con ~150 ítems adicionales por clase, McNemar tendría potencia suficiente para decidir si la mejora sobre el maestro es real.

Prioridad 2 — Refinar la rúbrica para mixtos adversativos (impacto alto · esfuerzo bajo). La brecha ordinal−nominal señala que el desacuerdo es de umbral. Redactar reglas explícitas («si la crítica pide un cambio concreto, la etiqueta es la de la crítica») y re-anotar los 48 ítems de mayoría simple debería elevar α por encima de 0,70 sin anotar nada nuevo.

Prioridad 3 — Recolectar comentarios institucionales reales (impacto alto · esfuerzo externo). Solicitar a la universidad un volcado sin plantillar de un semestre. Resuelve L1, L2 y L5 de raíz y permite reentrenar sobre el dominio objetivo en lugar de un corpus traducido.

Prioridad 4 — Auditoría de sesgo por subgrupo (impacto alto · esfuerzo medio). Medir macro-F1 y recall NEG por asignatura, facultad y —si es legalmente posible y con consentimiento— género del docente. Es un requisito previo a cualquier despliegue con consecuencias (L11).

Prioridad 5 — Validar el modelo de tendencia con desempeño observado (impacto medio). Sustituir la etiqueta derivada por reglas por una señal real (evolución de puntajes en semestres posteriores, permanencia, resultados de aprendizaje). Sin esto, el 0,915 no es interpretable (L4).

Prioridad 6 — Análisis por aspectos (ABSA) (impacto medio · esfuerzo alto). Pasar de polaridad global a polaridad por aspecto (metodología · evaluación · trato · material). El DOFA gana precisión cuando distingue «explica bien pero califica injustamente» de un sentimiento mixto indiferenciado. Requiere el gold ampliado de la prioridad 1.

Prioridad 7 — Puesta en producción y monitoreo (impacto medio). Desplegar el servicio de §7, registrar la distribución de predicciones por semestre y alertar ante desviaciones (drift). Cerrar el ciclo: cada semestre anotado alimenta la siguiente versión del modelo.

Término Definición
α de Krippendorff Coeficiente de acuerdo entre anotadores que admite diseños incompletos y distintos números de anotadores por ítem. Nominal trata las clases como no ordenadas; ordinal penaliza más los desacuerdos lejanos
Adjudicación Proceso de convertir varias anotaciones en una única etiqueta de referencia (aquí: mayoría 2/3; sin mayoría → descartado)
Benchmark Comparación sistemática de varios modelos sobre el mismo conjunto de evaluación y las mismas métricas
Brier score Error cuadrático medio de las probabilidades predichas. Menor es mejor; mide calidad de calibración
Calibración isotónica Ajuste monótono que corrige probabilidades mal calibradas sin alterar el orden de las predicciones
Destilación de conocimiento Entrenar un modelo «estudiante» con las predicciones de un modelo «maestro» en lugar de etiquetas humanas
DOFA / SWOT Matriz de Debilidades, Oportunidades, Fortalezas y Amenazas
Entropía cruzada ponderada Función de pérdida que asigna más peso a las clases minoritarias para compensar el desbalance
Fine-tuning Continuar el entrenamiento de un modelo preentrenado sobre datos de la tarea objetivo, ajustando todos sus pesos
Fleiss κ Acuerdo entre más de dos anotadores sobre categorías nominales, corregido por azar
Fuga de información Uso, como variable predictora, de información que no estaría disponible en el momento real de la predicción. Infla las métricas de forma engañosa
Gold standard Conjunto de referencia con etiquetas consideradas correctas, contra el que se mide el desempeño
macro-F1 Media aritmética del F1 de cada clase, sin ponderar por frecuencia. Penaliza ignorar clases minoritarias
Mixto adversativo Comentario con elogio y crítica unidos por un conector adversativo («bueno, pero …»)

Paradoja de kappa Situación en la que el acuerdo observado es alto pero κ es bajo, porque el desbalance de clases eleva el acuerdo esperado por azar

Supervisión débil Entrenar con etiquetas generadas automáticamente (reglas, heurísticas u otro modelo) en lugar de anotación humana
Transfer learning Reutilizar un modelo entrenado en una tarea general para resolver una tarea específica con pocos datos

Anexo D · Guía de reproducción

1. Preparar el entorno

git clone https://github.com/Capstone-Tech-Tailors/Analitica-Educativa.git
cd Analitica-Educativa && git checkout dev/natalia
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

# Notebook Produce

3. Usar el modelo de producción

from transformers import pipeline

clf = pipeline(
    "sentiment-analysis",
    model="analisis_sentimientos/models/modelo_sentimiento_humano",
)
print(clf(["La profesora explica con claridad y responde todas las dudas"]))

4. Nota sobre reproducibilidad exacta

Las semillas están fijadas en 42, pero el backend MPS de Apple Silicon no es completamente determinista. Se observó una variabilidad entre corridas de hasta ±0,04 en macro-F1 sobre conjuntos de 20 ítems (L9). Sobre el gold de 172 la variabilidad es sustancialmente menor. Las cifras de este informe corresponden a las ejecuciones registradas en los notebooks del repositorio; una re-ejecución puede diferir en el tercer decimal.
